# Recursos interactivos · Evaluación de Tecnología Sanitaria

Páginas web interactivas para la asignatura «Evaluación de Tecnología Sanitaria» (59728) del Grado en Ingeniería Biomédica, Escuela Politécnica de Cuenca, Universidad de Castilla-La Mancha.

El caso guía es el informe de AQuAS y RedETS sobre protonterapia (2024).

## Contenido

| Tema | Recurso | Carpeta |
|---|---|---|
| 1 | La ETS de un vistazo | `tema1/ets-de-un-vistazo/` |
| 1 · Bloque 1: Evidencias | La revisión sistemática paso a paso | `tema1/revision-sistematica/` |
| 1 · Bloque 1: Evidencias | Cribado de estudios y diagrama PRISMA | `tema1/cribado-prisma/` |

| 1 · Bloque 1: Evidencias | La escalera GRADE y el riesgo de sesgo | `tema1/escalera-grade/` |

La página de inicio (`index.html`) enlaza todos los recursos. Enlaza también dos herramientas que viven en sus propios repositorios: el [Buscador de evidencia PICO](https://github.com/csmelendez/buscaPICO) y el [Clasificador de productos sanitarios MDR/IVDR](https://github.com/csmelendez/clasificaMD).

## Uso

Cada recurso es un único archivo HTML sin dependencias, salvo las fuentes de Google Fonts. Las presentaciones se navegan con las flechas del teclado; la tecla F activa la pantalla completa.

Para publicarlo con GitHub Pages: *Settings → Pages → Deploy from a branch*, rama `main`, carpeta raíz.

## Vigencia

Normativa comprobada a octubre de 2026. Las páginas resumen la normativa con fines didácticos y no sustituyen la consulta del DOUE ni del BOE. Los datos de los ejemplos de metaanálisis y de certeza GRADE son ficticios, como en los apuntes de la asignatura.
